# Security

Bug Hunter é uma ferramenta de análise estática. Ela **não executa o código analisado**.

Ao integrar a ferramenta em CI, prefira limitar permissões do job e trate arquivos de configuração do projeto como entrada não confiável.

Encontrou um problema de segurança no próprio Bug Hunter? Abra uma issue privada no repositório do projeto quando houver um endereço de security contact configurado.
